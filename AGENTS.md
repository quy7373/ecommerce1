# Ecommerce Agent Instructions

## Rules
1. Inspect the repository before editing.
2. Work only in your assigned Git worktree.
3. Never modify another agent's branch.
4. Do not invent API contracts or database fields.
5. Do not commit credentials or secrets.
6. Run relevant tests before reporting completion.
7. Do not merge or deploy without user approval.

## Roles
- Architect: requirements, architecture, API contracts, review.
- Backend: API, database, validation, backend tests.
- Frontend: UI, API integration, frontend tests.

## Completion report
- Task ID
- Files changed
- Tests executed
- Test results
- Known issues
- Commit hash
